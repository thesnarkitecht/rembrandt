# Rembrandt brand

The R logo, wordmark and app icons, under the same licence as the rest of Rembrandt
(GPL-3.0-or-later). Everything here is generated by `brand/src/make-brand.py`
(`pip install fonttools brotli`, then `python3 brand/src/make-brand.py`).

| File | Use |
|---|---|
| `r-mark.svg` | The R, flat bronze. Small sizes: favicons, the app header, dialogs. |
| `r-mark-halftone.svg`, `r-mark-halftone-light.svg` | The R drawn as bronze dots, lit from the top right like the website's paintings. 64 px and up, on dark or light backgrounds. |
| `rembrandt.svg`, `rembrandt-light.svg` | Lockup: the halftone R and REMBRANDT. |
| `app-icon.svg` → `/app-icon.png` | Desktop icon: warm ink tile, faint contour lines, the halftone R. `npx tauri icon app-icon.png -o src-tauri/icons` |
| `app-icon-small.svg` | The same tile with the flat R, for the 64 px and smaller icon files (`32x32.png`, `64x64.png`, `Square30x30Logo.png`, `Square44x44Logo.png`, `icon.ico`), where dots blur. |
| `app-icon-mobile.svg` | Phones: a full square (iOS rounds it and rejects transparency; Android masks it). iOS PNGs must have no alpha channel. |

The generator also writes `src/art/r-mark-halftone.svg` and `src/art/topo.svg` (contour lines the
app uses as a mask), because the app build copies `src/`, not `brand/`.

**Colours.** Ink `#0B0A09`, umber `#1A130C`, paper `#EBE5DA`, cream `#EEE8DE`; bronze
`#8A5829` / `#C98F4F` / `#F4D292` on dark (`#6A4019` / `#A8712F` / `#C98F4F` on light). In the
app these are the `--mark-1/2/3` tokens in `styles.css`; the flat mark uses `--mark-2`.

**Type.** Antonio (condensed, bold, caps) for the wordmark and titles, Instrument Serif italic for
the occasional accent word, Geist Mono in small caps for labels, Geist for text.

**Wordmark.** REMBRANDT in Antonio 700, tracking about 0.08em.
